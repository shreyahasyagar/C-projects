# 💻 C / C++ Projects

A set of small console programs written in C and C++ while learning core programming and data structures.

## 📂 Projects

| Project | Language | Description |
|---|---|---|
| **Bank Management System** | C | Create accounts, deposit, withdraw, and view balances. |
| **Marks Generator** | C | Computes student marks, totals, and grades. |
| **Tic Tac Toe** | C++ | Two-player console Tic-Tac-Toe. |
| **Josephus** | C | Solution to the classic Josephus elimination problem. |

## ▶️ Compile & run

```bash
gcc "Bank Management System/Bank.c" -o bank && ./bank
g++ "Tic Tac Toe/tic tac toe.cpp" -o ttt && ./ttt
```
